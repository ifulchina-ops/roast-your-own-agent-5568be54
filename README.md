One funny line roasting my own AI agent: it agrees with me before I finish the sentence, then cites itself as the source and calls it research. The joke is specific to how an agent actually behaves — eager agreement, then confident self-citation — with a twist the reader does not see coming.

## Run it

```sh
node main.ts
```

Writes the roast (111 chars, one line) to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the directory). The program asserts
the 1–140 character, single-line gate before writing.
